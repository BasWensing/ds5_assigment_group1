Exercise 1: Student Grades

Documentatie van het inlezen en analyseren van studentencijfers.

Doel van de oefening

Het programma leest studentgegevens uit een CSV-bestand. Daarna berekent het programma het gemiddelde cijfer en maakt het een rapport van studenten met een cijfer van minimaal 80.

Benodigde import

De Python-module csv is nodig om het bestand te lezen.

import csv

Voeg deze regel toe voordat csv.DictReader wordt gebruikt.

Invoerbestand

De gebruiker voert het pad naar een CSV-bestand in. Het bestand moet ten minste de kolommen Name en Grade bevatten.

Name Grade
Alice 90
Bob 75

Werking van het programma

  1. De gebruiker geeft het pad naar het CSV-bestand op.
  2. Het bestand wordt geopend met open.
  3. csv.DictReader leest elke rij als een dictionary.
  4. De dictionaries worden opgeslagen in de lijst records.
  5. De cijfers worden opgeteld en gedeeld door het aantal studenten.
  6. Alle studenten met een cijfer van minimaal 80 worden geselecteerd.

Belangrijkste code

file_path = input("Enter the path to the CSV file: ")
records = []

with open(file_path, 'r') as file:
    csv_reader = csv.DictReader(file)
    for row in csv_reader:
        records.append(row)

total = sum(float(record['Grade']) for record in records)
average = total / len(records)

filtered_records = [
    record for record in records
    if float(record['Grade']) >= 80.0
]

Uitvoer

Het programma toont eerst het gemiddelde cijfer en daarna de geselecteerde studenten.

Average Grade: 82.5
--------------------
Student Report
--------------
Name: Alice
Grade: 90
--------------------

Mogelijke fouten

  • Het opgegeven bestandspad bestaat niet.
  • Het CSV-bestand bevat geen kolom met de naam Grade.
  • Een cijfer kan niet worden omgezet naar een getal.
  • Een leeg CSV-bestand veroorzaakt een fout bij het berekenen van het gemiddelde.
